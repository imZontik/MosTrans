# Магистраль 400

Геймифицированный тренажёр для проводников высокоскоростной магистрали (ВСМ). Сотрудник проходит нештатные ситуации — от конфликта пассажиров до медицинского инцидента: принимает решения на время, видит последствия на шкалах «Лояльность пассажира» и «Рейтинг безопасности» и зарабатывает очки компетенций.

Команда «Кокаманы», трек «Геймификация для ВСМ», хакатон Московского транспорта.

## Возможности

**Для сотрудника**
* **Движок нелинейных сценариев**: диалоги с ветвлением, таймеры 10–30 с на критические решения, свободные ответы, которые оценивает ИИ-наставник.
* **Курсы по должностям** (проводник → старший проводник → начальник поезда). Сценарии следующей должности открыты как «повышение квалификации» и приносят ×1.5 очков.
* **Зоны ответственности**: задания «решить самому или позвать коллегу». Маскот — Вова-механик.
* **Специвенты**: посреди рабочего дня внезапно приходит экстренная ситуация с голосовым сообщением, сотрудник учится воспринимать информацию на слух. Хард-левел — голосовое на английском.
* **Еженедельный турнир**: все заходят одновременно и быстро отвечают на вопросы на время. Топ-10 получают ачивку и +100 к рейтингу.
* Профиль, уровни, 14 ачивок и трофеи турниров, рейтинг за неделю и за всё время.
* **Адаптивная сложность**: система подбирает следующий сценарий по слабым местам.

**Для руководителя и HR**
* Дашборд: активность, успешность по категориям, динамика безопасности, частые ошибки.
* Карточки сотрудников: готовность к повышению и перевод на должность выше.
* **Генерация сценариев ИИ**: по ТЗ инструктора собирается черновик ветвящегося сценария, его можно отредактировать и опубликовать.
* **ИИ-ассистент**: например, «Покажи всех проводников, у кого упал рейтинг безопасности за месяц».
* Запуск специвента для всех сотрудников или для выбранных, управление турнирами.

## Запуск

```bash
cp .env.example .env
docker compose up -d --build
```

* Приложение: http://localhost:8080
* API (Swagger): http://localhost:8080/api/docs
* Prometheus: http://localhost:9090

При первом запуске создаются 8 учебных сценариев, 4 специвента, 35 сотрудников с историей обучения, прошедший турнир и **турнир, который идёт прямо сейчас**.

| Роль | Логин | Пароль |
|---|---|---|

| Руководитель | lead@m400.ru | lead123 |

Сбросить демо-данные:

```bash
docker compose down -v
```

### Подключение LLM

По умолчанию `ML_PROVIDER=heuristic`: работает офлайн, без ключей.

**GigaChat.** В `.env` задать `ML_PROVIDER=gigachat` и `GIGACHAT_AUTH_KEY=<ключ авторизации>`.

**Локальный Qwen** (open-source, данные не покидают контур):

```bash
docker compose --profile qwen up -d
docker compose exec ollama ollama pull qwen2.5:3b
```

Затем задать `ML_PROVIDER=ollama` и перезапустить `ml-service`.

### Web view

Приложение адаптивное и встраивается в любое приложение или мессенджер как web view. Токен сотрудника можно передать в URL: `https://host/?token=<jwt>`.
